# ICP — целевая аудитория white-label PWA записи для детейлинг-студий

Дата: 2026-10-09 · Статус: рабочая версия после провала волны «30 лидов» (10 касаний → 1 демо → отказ)

---

## 1. Кто это

**«Занятая студия без системы, где хозяин ещё в операционке»**

Студия, у которой **поток уже есть** (поэтому теряют деньги на звонках и директе), но **системы записи нет**, а решения принимает **сам владелец**, а не админ и не закупщик.

### Почему именно они

| Сегмент | Проблема | Вердикт |
|---|---|---|
| Мастер-одиночка, 2–3 клиента в неделю | Мало потока — онлайн-запись не болит | ❌ не ЦА |
| **Студия 2–4 мастера, хозяин ещё принимает записи** | **Звонки в работе, заявки в DM, нет слотов — теряют деньги** | ✅ **ЦА** |
| Студия с отдельным админом / ресепшеном | Сообщение уходит админу, он не ЛПР | ⚠️ только в личный контакт хозяина |
| Сеть, несколько точек, автоцентр | Закупки, чужие CRM, длинный цикл | ❌ не ЦА при «дёшево и массово» |
| Уже Yclients / Zapisi | Боль закрыта, высокий порог переключения | ❌ не ЦА |
| Только мойка / шиномонтаж / СТО | Другая экономика и сервисы | ❌ не наш продукт |

### Болевой момент (1 фраза)

> «Пока я делаю машину — телефон звонит и теряется, в директе 5 переписок „а когда свободно?“, клиент не видит цену и время.»

### Триггеры «поток уже есть» (фильтр сбора)

Любой **2+** из списка:
- Отзывы: на **2gis.by** шкала низкая (макс ~10) → порог 5+; на **Яндекс.Картах** — 20+/50+
- Регулярные посты с работами (≥2–4 в месяц)
- Есть реклама (av.by promoted, таргет)
- В описании «запись заранее», «свободные окна», жалобы «не дозвонился» в отзывах
- Указаны цены (значит, конвертируют, а не «созвонимся»)
- Сильный digital-след: сайт + IG + WhatsApp/Telegram

## 2. Профиль решения (кто платит)

| Параметр | Значение |
|---|---|
| ЛПР | Собственник (часто он же мастер / бренд-лицо) |
| Где найти ЛПР | Личный телефон с 2GIS (он же рабочий), WhatsApp, TG из bio, личный IG. **Не** студийный аккаунт |
| Решение | Импульсное, 1 звонок / 1 демо. Без «спрошу у начальства» |
| Бюджет | Дёшево и массово: стоимость ≈ 1–3 мойки в месяц, а не «проект по разработке» |
| Порог доверия | Высокий («меня кидают», «это развод»). Демо на их услугах и ценах обязательное |
| Страх | «Дорого / сложно / буду разбираться полгода» → снимать: «1 день, без разработчиков, без подписки как Yclients» |

## 3. География

**Фокус:** Минск + областные города 100к+

Минск · Гомель · Могилёв · Витебск · Брест · Гродно · Бобруйск · Барановичи

Почему не глубинка без потока, и не только Минск: в областных слабее Yclients, чаще запись «по звонку», хозяин доступнее, цена решения воспринимается спокойнее.

## 4. Фильтры сбора (что кладём в базу)

> **Ограничение источника (проверено 2026-10-09):** веб-версия `2gis.by` сейчас отдаёт поиск **только по Минску**. Региональные города (`/gomel`, `/brest` и т.д.) возвращают «Ничего не нашлось» на любые запросы. Парсер `parser-2gis-new` для Минска работает. Регионы — через Яндекс.Карты / av.by / taplink (см. §9).

Берём карточку, если **все** обязательные:

1. ✅ Город из списка фокуса
2. ✅ Рубрика: детейлинг / полировка / оклейка плёнкой / химчистка кузова (не только «мойка»)
3. ✅ Есть телефон (обязательно) — иначе не отработаем
4. ✅ Есть WhatsApp **или** соцсети/мессенджеры (цифровая доступность)
5. ✅ Не франшиза / не сеть (1 точка)
6. ✅ Отзывы ≥ 30 (прокси «поток есть»)
7. ✅ Рейтинг ≥ 4.2 (работают на качество, им важна репутация)
8. ✅ **Нет** Yclients/Zapisi в ссылках и **нет** живой онлайн-записи на сайте

Не обязательно иметь сайт. Сайт-визитка **без** записи — ок.

Доп. поля для скоринга (заполняем вручную/парсингом):
- Telegram владельца
- Имя владельца
- Сколько отзывов
- Признаки «потока»
- Был ли контакт / ответ

## 5. Скоринг лида (0–10)

| Балл | Признак |
|---|---|
| +2 | Телефон + WhatsApp/TG |
| +2 | Отзывы 50+ |
| +2 | Нет сайта вообще (запись только в DM/звонок) |
| +2 | Найден личный контакт владельца (не ресепшен) |
| +1 | Активные соцсети с работами |
| +1 | Город фокуса, рейтинг 4.5+ |
| −3 | Есть Yclients/Zapisi |
| −3 | Автоцентр/СТО/сеть/франшиза |
| −2 | Только админ-аккаунт, владелец не найден |

**В работу: 6+.** Лучшие: 8–10.

## 6. Месседжинг (почему «не верят»)

Старый крючок «сделал вам приложение» — звучит как дорогая разработка и лохотрон.

Что работает на этот сегмент:
- **Не** «приложение», а «ссылка на онлайн-запись» / «страница записи под ваш бренд»
- Конкретная боль: «не дозвонился / потерялся в директе»
- Сравнение с привычным: «как запись в салоне красоты, только ваш студии»
- Цена против Yclients: «без подписки как в Yclients, подключается за день»
- Демо на **их** услугах и ценах — единственный рабочий снять страх
- Оффер после демо: «попробуйте месяц дёшево / платите когда увидите записи»

Канал: личный TG/WhatsApp хозяина или короткий звонок. Не форма студийного аккаунта.

---

## 7. Анти-ЦА (в базу не тащим)

- Yclients / Zapisi / 1С / своя CRM
- Франшизы и сети (Bling, крупные мойки с филиалами)
- Автоцентры с СТО (AutoBogov-тип)
- Одинокие мастера без потока и отзывов
- Карточки без телефона и без мессенджера
- Шиномонтаж / только мойка / только тюнинг без детейлинга

---

## 8. Связка с продуктом

- White-label PWA: услуги, цены, фото, слоты, кабинет хозяина — `AI-HANDOFF.md`
- Демо за день: `npm run new-client -- slug` + `npm run ship -- slug`
- Коммерция: дёшево и массово → стандартное демо, минимум кастомизации, self-serve онбординг
